# Wireframes — Pé-de-meia

Prévia clicável da experiência (mid-fi). **Não** é o app Next.js.

## Como abrir

1. Abra [`index.html`](./index.html) no Chrome/Edge (duplo clique ou arrastar para o browser).
2. Ou no PowerShell, na raiz do repo:

```powershell
start docs/wireframes/index.html
```

Navegue pela sidebar e pelos botões Continuar / CTAs.

## Fluxo sugerido

Setup 1 → 2 → 3 → **Home** → **Caixa** → **Projeção** → Compromissos

## O que cada tela prova

| Tela | Insight |
|------|---------|
| Setup | Folga aparece antes de lançar o dia |
| Home | Veredito + coach de estilo de vida |
| Caixa | Heatmap: vermelho **quando** e **por quantos dias** |
| Projeção | Trechos vermelhos multi-mês + sugestão |
| Registrar | V2: “como pagou?” |
